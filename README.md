# English Quiz

A simple English vocabulary quiz built with HTML and JavaScript.

## Features

* Multiple-choice questions
* Score tracking
* Final performance feedback
* User input with prompts
* English vocabulary practice

## Technologies

* HTML5
* JavaScript

## What I practiced

* Variables
* Arrays
* Loops (`for`)
* Conditionals (`if / else`)
* User input with `prompt()`
* Template literals
* Git and GitHub workflow

## How to use

1. Open the project in your browser.
2. Answer each question by typing:

   * `a`
   * `b`
   * `c`
3. View your final score and feedback.
